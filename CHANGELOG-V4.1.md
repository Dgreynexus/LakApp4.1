# LakApp V4.1 — Libas Visual Handbook

V4.1 builds on the working LakApp4 PWA and keeps the supplied handbook content intact.

## Visual upgrades
- Libas NHS color system: royal blue, bright yellow, cyan, red, green
- Official supplied Libas NHS logo retained
- Animated visual banner for every handbook chapter
- Chapter-specific quick-view cards
- Student rights visual grid
- School-hours animated timeline
- Discipline visual strip
- Mobile-friendly horizontal timeline
- Reading progress reset
- Fresh service-worker cache version

## Content integrity
The substantive handbook text was preserved from the existing LakApp4/V3 source. Visual cards are summaries derived from the corresponding chapter text and are not intended to replace the source wording.
